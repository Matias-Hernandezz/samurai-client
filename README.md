# Samurai Client

Cliente / storefront del proyecto Samurai.

## Desarrollo (pnpm)

```bash
pnpm install
pnpm dev      # http://localhost:5173
pnpm build
pnpm audit
```

Stack: **React 19**, **Vite 8**, **TypeScript 7**, **pnpm**.

La API vive en el repo **samurai-admin** (`backend/`, puerto 8001).
